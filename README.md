
# ✊✋✌️ Rock, Paper, Scissors Game (Python)

## Description
This is a command-line Rock, Paper, Scissors game built using Python.  
The player competes against the computer, and the first to win two rounds (best of three) wins the game.

This project was created to practice Python fundamentals such as loops, conditional statements, user input handling, and random choice generation.

---

## Features
- Best-of-three gameplay
- Player vs Computer mode
- Random computer choices
- Score tracking (player, computer, and ties)
- Input validation for user choices

---

## Technologies Used
- Python
- random module
